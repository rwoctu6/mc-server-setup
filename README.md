# MC开服教程：从选配置到拉朋友进游戏，新手也能一次开成功

想和朋友一起玩 MC，卡住的地方通常不是"怎么点"，而是三个问题：服务端选哪个、配置买多大、端口怎么通。这三个问题想明白了，后面的操作其实十几分钟就能走完。

这篇按实际流程写一遍：先搞清楚你要开的是什么服，再决定机器买多大，最后用现成的面板把服务跑起来。文中涉及的价格和套餐都以雨云当前公开页面为准，买之前建议自己再确认一眼。

## 先定三件事，再花钱

顺序反了会白花钱。

**第一，Java 版还是基岩版。** Java 版是 PC 端主流，Mod 生态最全；基岩版覆盖手机、主机、Win10 版。两者端口不一样：Java 版默认 TCP 25565，基岩版默认 UDP 19132。Java 服基岩版玩家进不来，除非额外做跨版本方案。

**第二，原版、插件还是模组。** 这决定了钱花在 CPU 还是内存上：

| 服务端 | 适合什么玩法 | 说明 |
| --- | --- | --- |
| Vanilla 原版 | 纯原版生存 | 官方发布，兼容性最好，性能一般 |
| Paper / Purpur | 加插件、要流畅 | 优化版，支持 Bukkit/Spigot 插件生态 |
| Forge | 大型模组整合包 | Mod 生态最成熟，吃内存 |
| Fabric | 轻量模组 | 启动快，新版本适配及时 |

纯生存选 Paper 基本是共识；玩整合包先看整合包要求哪套框架，再倒推游戏版本和 Java 版本。

**第三，多少人玩。** 这个数字直接决定内存买多大，别为了"以后可能有人来"直接上顶配。

## Java 版本和内存，两个最容易踩的坑

Java 版本装错，服务端直接起不来：

| MC 版本 | 需要的 Java |
| --- | --- |
| 1.16 及以下 | Java 8 |
| 1.17 ～ 1.20.4 | Java 17 |
| 1.20.5 及以上 | Java 21 |

用 Docker 或者一键开服的面板，通常会自动匹配 Java 版本，这一步就省了。

内存方面，服务端自身要吃 1GB 上下，每个在线玩家再加几百 MB，模组另算——大型整合包几十个 Mod 的内存需求可能是原版的好几倍。分配给 MC 的内存建议占服务器总内存的 60%～70%，留一部分给系统。

还有一点经常被忽略：MC 的主逻辑跑在单线程上，**单核主频比核心数重要**。4 核 8G 的低频机器，实际表现可能不如 2 核 4G 的高频机器。

按人数粗估：

- 2～5 人原版生存：2 核 4G（分配给 MC 2～3G）
- 5～15 人原版加少量插件：2～4 核，4～8G
- 10 人以上大型整合包：4 核，8～16G 起步

## 自己拿 VPS 装，还是买现成面板服

两条路线的差别不在性能，在你愿意花多少时间。

**VPS 路线**：给你一台干净的 Windows/Linux 机器，Java 环境、服务端核心、端口映射、开机自启都自己来。好处是自由，能挂群组服、能跑自己写的脚本；代价是新手至少要折腾一两个小时，出问题得自己排。

**面板服路线**：服务端跑在容器里，全程网页操作，选好服务端和版本点一下就行。适合新手和单端场景，缺点是只能在指定镜像里跑，一般不支持群组服。

如果你只是想让朋友今天就能进服，面板服是更短的路。

## 用面板服开服，实际流程是这样

以 MCSM 面板为例，走一遍完整路径。

**1. 注册并进控制台。** 注册后绑定微信，系统会发一张首月 5 折券，这是新用户能拿到的固定最大折扣。👉 [先领首月5折券再选购游戏云](https://www.rainyun.com/MzA2MTc2_)

**2. 买游戏云，选面板类型。** 控制台的"总览"或"云产品"里能找到游戏云入口。类型选 MCSM 面板，然后挑服务端。

**3. 挑服务端。** 一键开服支持的清单包括 Minecraft Java 版、基岩版，另外还有泰拉瑞亚和饥荒。Java 版直接可选 Arclight、Mohist、CatServer、SpongeForge、Thermos、Uranium、Fabric、Waterfall、BungeeCore、Velocity。注意 **Forge 不在这个列表里**，想开 Forge 得选"纯 Java 环境"，自己上传服务端核心。

**4. 选配置和计费模式。** 列表里没你想要的版本组合时，选纯 Java 环境，再按版本对应挑 Java 大版本。配置按前面的估算来，玩高版本模组服建议 4 核 8G 往上。计费模式分固定和动态两种：天天都有人在线、CPU 长期跑高，用固定计费省心；只有晚上几个人上来玩两小时，动态计费更划算——它按每天的 CPU 消耗额外结算，闲置时段的花费能压下来一大截。

**5. 等创建完成，进面板开机。** 一般 1～5 分钟。在管理页点"进入 MCSM 管理面板"，用提示的账号密码登录，点开机，等控制台打出 `Done` 就成功启动了。

**6. 配 NAT 端口映射。** 这一步最容易卡住。默认是 NAT 机型，共用公网 IP，需要把内部端口映射到外部端口：

- 游戏类型选 MC Java 版，协议选 TCP，内网端口 25565
- 基岩版则选 UDP，内网端口 19132

新建映射后，你会拿到一个类似 `xxx.rainplay.cn:22293` 的地址。

**7. 进游戏。** 启动和你服务端版本完全一致的客户端，多人游戏里粘贴这个地址。版本对不上会直接连不进去。

整个流程里，唯一需要手动改文件的情况是你选了纯 Java 环境跑 Forge——需要先跑一次 `--installServer` 安装，再改 `run.sh` 的 JVM 参数启动。

## 连不上服务器，先查这四个地方

开服失败十有八九集中在这几种情况：

1. **版本不一致。** 客户端和服务端版本必须完全相同，1.21.1 的客户端连不上 1.21.4 的服。
2. **正版验证。** 服务器默认开启 `online-mode`，离线启动器的玩家会被拒。改 `server.properties` 里的 `online-mode=false` 可以关掉。基岩版默认就是关的。
3. **EULA 没同意。** 控制台提示 `You need to agree to the EULA` 就是这个问题。用雨云面板服的话系统会替你处理，自己用 VPS 搭要手动把 `eula.txt` 里的 `false` 改成 `true`。
4. **端口没通。** 检查内网端口填的是不是服务端实际监听的端口，外部端口有没有被占用。

还有一种情况：服务器开着但没人进，几分钟后控制台冒出 `Server empty for 60 seconds, pausing`。这是空服自动暂停省资源，有人进来会自己恢复，不用担心。

## 怎么把每个月的钱花少一点

几个实际能用的省钱方式：

- **首月 5 折券。** 注册绑定微信后发放，新用户专属，是最直接的一笔折扣。券有有效期，别放着过期。
- **动态计费 / 按天计费。** 面板服支持按天算，不开服就不产生那天的钱。朋友只在周末上线的话，这个比包月划算得多。
- **年付折扣。** 确定要长期开服，年付比月付便宜一截，官方教程里提到年付 7 折。先用 5 折券开一个月跑顺了，再考虑转长期。
- **1 元试用 1 天。** 换机型换区域之前，花 1 元测一天延迟和实际 TPS，比看评测直观。
- **积分。** 每日签到、做任务能攒积分，积分可以兑换游戏云和 CPU 电量。官方也会不定期上架积分兑换的服，刷新时间不固定，能不能抢到看运气。

另外，雨云支持 7 天无理由退订。买了发现延迟高、跑不动你的整合包，在期限内退掉就行。

## 常见问题

**2 核 4G 够开几个人的服？**
纯原版生存配 Paper，10 人以内问题不大。但如果装了几十个 mod，2 核 4G 会很快吃满，先按官方给的承载参考打个七折估算更稳。

**面板服和 VPS 到底选哪个？**
只想开一个服、想省事，选面板服。要开群组服、要挂机器人框架、要做服中服，选 VPS。

**Bandwidth 要加吗？**
原版服一个玩家大概占 1.5M 上行，10 人来访 15M 基本够。带宽不够会导致 TPS 下降，但盲目加带宽也解决不了 mod 服卡顿——那通常是内存和单核性能的问题，先查这两个。

**能同时开多个版本吗？**
面板服默认一个容器一个服务端，想多开就买多台，或者上 VPS 自己用 Docker 起多个实例。

**换机器会丢存档吗？**
不会，但需要自己做备份和迁移。雨云的控制台提供自动备份功能，开服后就把它打开，别等出事才想起来。

配置这件事没有标准答案，最省心的做法是先用 1 元试用或者首月 5 折券开一个月，把你的整合包真跑一遍，看 TPS 稳不稳、几个人同时在线会不会掉线，再决定要不要升配。👉 [从雨云游戏云页面按自己的玩法挑配置](https://www.rainyun.com/MzA2MTc2_)
